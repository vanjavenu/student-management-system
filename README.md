# Student Management System

A desktop GUI application built with Python for managing student records. 
The app allows users to add, view, sort, and organize student information, 
with the ability to export data to Excel.

## Features
- Add and manage student records
- Sort students by different fields
- Export student data to an Excel spreadsheet (students.xlsx)
- Local database storage (students.db)

## Files
- gui_with_sorting.py – Main application file with the GUI and sorting logic
- students.db – SQLite database storing student records
- students.xlsx – Sample/exported student data in Excel format
